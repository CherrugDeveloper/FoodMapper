# FoodMapper

FoodMapper is a comprehensive, multi-language nutritional tracking, diet planning, and health management web application built with React, TypeScript, and Tailwind CSS.

## Features

- **Nutritional Calculator**: Calculates personalized caloric and macronutrient targets based on user metrics and health conditions.
- **Diet Plan Generator**: Generates structured daily meal plans across various phases and tracks compliance.
- **Diary**: Tracks daily food intake, water consumption, symptoms, and bowel transit scores.
- **Recipes**: Comprehensive recipe database with ingredient breakdown, preparation instructions, and compatibility checks.
- **Shopping List**: Automated shopping list generation grouped by category and weekly trips.
- **Sleep & Workout Trackers**: Sleep monitoring, advice, and structured workout routines.
- **Internationalization**: Fully localized in English [`en`](public/locales/en/translation.json), Italian [`it`](public/locales/it/translation.json), German [`de`](public/locales/de/translation.json), Spanish [`es`](public/locales/es/translation.json), and French [`fr`](public/locales/fr/translation.json).

## Tech Stack

- **Framework**: React 18 with TypeScript & Vite
- **Styling**: Tailwind CSS
- **State & Storage**: React Context, LocalStorage
- **Internationalization**: i18next & react-i18next
- **Testing**: Vitest & Playwright

## Getting Started

### Prerequisites

- Node.js (v18+ recommended)
- npm

### Installation & Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Run test suite
npm test

# Build for production
npm run build
```
