# FoodMapper

FoodMapper is a progressive web application (PWA) designed for personalized diet planning, nutritional calculation, recipe management, sleep tracking, and workout logging, built with React, Vite, TypeScript, Tailwind CSS v4, and i18next.

## Features

- **Personalized Diet Plan**: Multi-phase diet progression with timezone-aware day calculations, DayNavigator, and PhaseProgress component.
- **Nutritional Calculator**: Advanced calculation engine for daily macros, calories, and micronutrient tracking.
- **Food Search & Filtering**: Bilingual food database with seasonal food tagging and FODMAP details.
- **Diary & Workout Tracking**: Daily food logging, meal breakdown, exercise figures, and progress monitoring.
- **Sleep & Wellness**: Sleep dashboard, sleep sounds, and notification permission handling.
- **Internationalization**: Fully bilingual/multilingual support via i18next.

## Getting Started

### Prerequisites

- Node.js (v18+ recommended)
- npm or pnpm

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/cherrugdeveloper/FoodMapper.git
   cd FoodMapper
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```

## Testing

Run unit tests:
```bash
npm test
```

Run E2E tests:
```bash
npm run test:e2e
```
